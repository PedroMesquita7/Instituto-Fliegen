## Etapa 1 — Combinar com o Instituto Fliegen (antes de publicar)

- [ ] Confirmar o que eles querem no site (regras? táticas? aberturas?) e quem atualiza a pontuação.
- [ ] Combinar **quando e como** os alunos vão usar o site (uma aula/oficina presencial é o ideal) e quem acompanha.
- [ ] Pedir autorização para usar o **logo e o nome** no site.
- [ ] Avisar que você vai precisar, depois da aplicação, de uma **declaração assinada e carimbada** (modelo em `docs/modelo-declaracao.docx`).
- [ ] Combinar as **autorizações dos responsáveis** para qualquer foto com alunos menores.

## Etapa 2 — Preparar e publicar o site

- [ ] Ajustar textos, rodapé e o que o Instituto pediu.
- [ ] Importar a planilha de torneios e ligá-la ao site (`planilha/COMO-USAR.md`) e **testar com dados reais**: crie uma aba de teste e veja se ela aparece como um novo torneio. Use só primeiro nome ou apelido.
- [ ] Abrir `verificar-problemas.html` e ver "Tudo certo".
- [ ] Publicar no GitHub Pages (README, seção 2) e testar o link no celular.
- [ ] Gerar um **QR code** do endereço do site (qualquer gerador gratuito) para imprimir e colocar na sala/nos torneios.

## Etapa 3 — Aplicar com a comunidade

- [ ] Fazer a oficina/aula com os alunos usando o site. Se possível, deixe-os usar no próprio celular ou nos computadores do Instituto.
- [ ] Anotar: data, local, quantas pessoas participaram (alunos, responsáveis, instrutores) — **esse número real vai no campo 3 do AVA**.
- [ ] Tirar fotos **só com autorização dos responsáveis**. Prefira fotos em que os menores não apareçam de frente, ou só as telas e o ambiente.
- [ ] Aplicar um feedback curto (modelo abaixo) e guardar os prints das respostas.

### Modelo de feedback (Google Forms, sem pedir nome)

Na primeira linha do formulário: *"Não escreva seu sobrenome. Suas respostas ajudam a melhorar o site."*

1. Você é: aluno(a) / responsável / instrutor(a) / outro
2. Foi fácil usar o site? (1 a 5)
3. As explicações das regras ficaram claras? (1 a 5)
4. Os problemas ajudaram a treinar? (1 a 5)
5. Você conseguiu usar no celular? (sim / mais ou menos / não)
6. Você usaria de novo? (sim / talvez / não)
7. O que você mais gostou? (resposta curta)
8. O que podemos melhorar? (resposta curta)
